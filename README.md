# DSA & Competitive Programming Learning Hub

This is a Next.js application designed to be an interactive learning hub for Data Structures, Algorithms, and Competitive Programming.

## Features

- **Interactive Curriculum**: Browse subjects and topics in a structured manner.
- **Problem Bank**: Practice solving problems with an in-browser code editor.
- **User Progress Tracking**: Keep track of your progress through subjects and problems.
- **Authentication**: Secure user authentication using Supabase.

## Getting Started

To get a local copy up and running, please follow the detailed instructions in the **[SETUP.md](SETUP.md)** file.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org)
- **Database**: [Supabase](https://supabase.io)
- **ORM**: [Drizzle ORM](https://orm.drizzle.team)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com)
